## 范围说明

“甲骨文所有字”不是一本可以一次写完的线性书。卷一先立体例与证据链；后续按天部、地部、人部、动物、器物、数字、动作、抽象关系分卷续编。每字必须保留：字头、片号、拓片出处、释文出处、摹本状态、置信度。
