从“猜字”到“证据生成”

把当前甲骨文智能研究、我们的 912 字位语料，和大模型的可验证能力接成一条线

路线页 2026-11-18配套：甲骨文认知密度报告打开数据报告打开证据校验器

大模型最值得做的，不是替人“认出一个字”，而是把散落在拓片、摹本、释文、字编里的证据组织成候选，再让另一个校验器把没有出处的候选打回去。真正能突破的，是“证据级生成”，不是“更像甲骨文的图”。

一、三种“认知密度”，不要混成一个数

维度商代甲骨书写现代人类大模型
密度落在哪字 + 片 + 辞例 + 共同仪式知识词 + 句 + 篇章 + 可查的外部知识参数记忆 + 上下文窗口 + 检索到的证据
单字负载字形可以简，意义靠槽位和语境补词义相对显式，靠句法消歧token 的表征是分布式的，不等于一个义项
解码成本高：需字编、辞例、考古背景中：需教育和专业训练生成门槛低，校验成本高
主要失败残片、缺字、误释、以今律古歧义、专业壁垒、记忆偏差幻觉、过度补全、来源缺失
能否造新字有构件组合，但受当时体系约束可造新词，不轻易造字形可生成字形，必须标证据等级
结论：“商代认知密度高”不等于“每个甲骨字都装着很多义项”。更准确的说法是：它把密度放在共享的仪式语境和格式槽位里；现代人把密度放在显式词汇和篇章里；大模型把密度放在参数和上下文里。三者不能用一个“熵”直接比大小。

二、当时的“认知词汇”实际在做什么

甲骨卜辞不是今天的散文，也不是面向大众的传播。它主要是商王室与祖先、神灵、天时之间的询问与记录：今天下雨吗、王会出行吗、田猎有获吗、某地受年吗、疾病与梦兆如何、征伐是否受佑。它的“沟通”对象首先是神祖与王室共同体，“解释”方式不是因果说明，而是卜问—验验—记事的程序。

从我们这套书选字看，认知词汇落在几个很实在的语域：天象（雨、风、日、月）、农事（田、禾、年）、动物（牛、羊、犬、鹿）、战争（伐、征、狩）、祭祀（祭、燎）、身体与梦（疾、梦）、王权与贞人（王、贞、卜）。这些词不是为了“文学”，而是为了在不确定的生活里做判断：年成、出行、疾病、战争、祭祀。也正因为目的明确，格式词（贞、卜、其、于、亡）才占据了网络核心。

四、真正的四个突破口

1. 从“猜一个答案”改成“给一组带出处的候选”

模型对未释字的最大价值，不是断言“这个字就是某字”，而是给出 Top-k 候选，并为每个候选附上：字形构件、同片辞例、字编页码/著录号、反证项。评测指标也随之改变：Top-k 命中率、来源覆盖率、专家推翻率。OBI-Bench 已经显示，模型在“释读”上能给出有创意的人类水平猜测，但细粒度感知仍低于人类；所以候选生成可以放开，断言必须收紧。

2. 从“单字识别”走到“片/句级语境”

我们的 912 字位最有价值的地方，不是字多，而是每个字都带着卷、篇、同片释文。它适合做“字—片—辞例”的证据检索：给定一个残损片段，模型先检索同片共现，再排候选，而不是只看字形。S-OBI 的结论也说明，整句级理解是当前模型的短板；谁先把“片级上下文”接进模型，谁就先突破。

3. 从“识别”走到“有约束的拟形”

“复刻未有之甲骨文”可以成立，但必须分四级：A 有拓片/摹本；B 有字形库+辞例；C 只用已见构件做类推；D 模型自由拟形。A/B 才能叫“复原”，C 只能叫“推演字”，D 只能叫“甲骨风拟字”。没有这四级，生成越像，越危险。

4. 从“准确率”走到“认知密度”

认知密度不能只用 perplexity 或字符准确率衡量。至少要有三类指标：一是同一字在不同辞例中的义项/槽位多样性；二是人类专家与模型在同一批字上的标注一致性；三是“给同样的证据，模型是否给出同样可复核的候选”。这也是我们那份 912 字位报告真正能接上的地方：它已经把“字形复杂度”和“上下文熵”分开测量了。

七、生成“未有之甲骨文”的硬规则

  • 分级：A 拓片/摹本；B 字形库+辞例；C 已见构件类推；D 自由拟形。输出必须带 level，不允许把 C/D 写成“复原”。
  • 不补笔：残损、断口、缺笔保留；模型可以提“可能补笔”，但必须另开字段，不能混进描摹层。
  • 不冒充：不得写“新出土”“原拓”“商代新字”；只能写“拟形/推演字/待核”。
  • 可反证：每个候选至少给一条能推翻它的证据类型：构件不通、辞例不合、时代不合、来源缺失。

八、三十天可执行计划

阶段做什么验收
第 1 周把 912 字位、同片释文、SVG、卷/篇做成证据表；接入 EVOBC/OBIMD 的公开字段每个字有 source_id；无来源字段为 0
第 2 周做 20 字试点：每字 3 个候选、来源、构件、反证；三人独立复核Top-3 命中率、来源覆盖率、专家推翻率
第 3 周做“残片补全”与“构件拟形”两组任务；D 级单独隔离补笔违规率 = 0；D 级不进入“复原”集
第 4 周把任务卡、评分脚本、错误案例公开；写一份“模型能做什么/不能做什么”可复现；外部研究者能跑同一批题
一句话：让大模型做“候选的放大器”，不要做“结论的替身”。它可以把 912 个字位变成一千条可检验的假设；但每条假设都要能回到片、回到辞、回到出处。
