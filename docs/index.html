为什么是“一图一字一详解”

甲骨文不是“看图猜字”。一个字要同时过四道关：字形是否有拓片或摹本依据、字源是否能落到先秦构形、同片释文是否能读通、后世字义如何层累。四关都过，才写“已核”；只过部分，就写“中”或“待核”。这一套写法，是把字放回它出生的那片甲骨、那顿饭、那场雨、那次战争里。
