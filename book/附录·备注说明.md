# 附录 · 备注说明

> 本附录面向拿到本书的读者，说明体例、证据层级、缩写、选字原则、版本口径、版权边界与引用方式。事实以仓库现有 README、CHANGELOG.md、VERSION、NOTICE.md、glyphs/LICENSES.md、CITATION.cff 与卷一至卷十一正文为准；不确定处标注“待核”。

## 一 · 本书是什么，不是什么

本书是一部**按事类分卷、逐字增补的甲骨文读本**，不是“甲骨文全部字已收完”的字典。

- 全书共 **77 卷**，每卷十二字，合计 **924 字位**；各卷含前卷重读，去重后为 **905 个唯一字**。
- 分卷按事类展开（天地人、身体与心、动作与生活、关系与共同体、器物与制度、自然与动物、天象与灾异、祭祀与信仰、战争与刑罚、王与臣、农事与田猎，直至卷七十七补遗与借字），不按《说文》部首或通用字表排序。
- 本书不宣称收齐甲骨文字头，不替代《甲骨文合集》《殷契文渊》等著录库；卷十二至卷七十七的字位以字位登记与证据登记为准，“详解”仅在卷一至卷十一范围内补齐（见第七节）。
- 未在本书出现的字头，不构成“该字无甲骨字形”的结论；待补、待核状态见各卷正文与 CHANGELOG.md。

## 二 · 体例

每一字位按以下顺序立件，卷页 Markdown 与阅读版 HTML 一一对应：

1. **字形图**：开源甲骨 SVG（`glyphs/` 目录，JGW 层），图注标“字形 · 复写”。
2. **拓片或摹本状态**：标明本片为拓片、另版摹本，还是“未见可读图 / 摹本待补”；状态逐条写在字头下，不以字形图替代拓片。
3. **字源**：定该字的构形与本义。字源只回答“字形由什么部件构成、本义落在何处”。
4. **详解**：在字源之后，按**形 · 辞 · 变 · 义**四层成文——形（构形与部件）、辞（卜辞用法与辞例）、变（金文至隶楷的演变）、义（本义与引申）。
5. **一字一世界**：把字放回它出现的片、事与场景中陈述。
6. **一字一智慧**：由该字本义与辞例引申出的理解性按语。
7. **同片释文摘句**：仅摘同一片甲骨的释文，不跨片拼合；释文过残者按各卷原样标“残”或“仅存残字”。

**字源与详解的分工**：字源定构形与本义；详解在字源基础上展开构形细节、卜辞用法、字形演变与引申义。详解不重复字源的结论，字源不承担卜辞辞例与演变梳理。

## 三 · 证据层级与标记

本书证据按下列层级标注，层级之间不混用：

- **拓片**：殷契文渊著录库所收《甲骨文合集》等著录的拓片缩略图，片号、SYSID 与记录号见字头行；缩略图不是高清原拓。
- **摹本**：另版摹本如与拓片不同片，明确标“另版”；未取得可读图的，写“未见可读图”或“摹本待补”。
- **同片释文**：仅取自该字所系同一片甲骨的释文，摘句照录原片行款与残字标记。
- **开源字形（JGW 层）**：来自 `zhouyongh/hanzi-glyphs-svg`，CC BY 4.0（来源与 DOI 见第八节）。开源字形是**摹形复写，不是拓片实证**。
- **待核 / 未见**：拓片—摹本逐字对照未完成、释文残缺或著录未命中处，标“待核”；未取得图版者标“未见”。
- **借字 / 后起字**：本片以假借字立形者标“借字”；后世才产生、甲骨无本字者标“后起字”，不以今字冒充甲骨原拓。

**本书没有把任何一字写成已核拓片**；凡只有字形库与合集号、尚未完成拓片对照的字位，状态行如实标注。检索未命中著录的字，不以模型记忆补拓片，不以别字冒充目标字。

## 四 · 引用与缩写

字头行与图注使用以下编号与缩写：

- **合**：《甲骨文合集》编号，如“合22453”“合6057正”；含**合补**（合集补编）、**合旅藏**等变体编号，变体随原著录照录，不改写成“合”。
- **SYSID**：合集数据库系统号，即殷契文渊库内该记录的系统编号，如“合6571正 · 甲骨文合集 SYSID 116109”（卷一）。
- **record**：殷契文渊拓片记录号，对应库内拓片记录 `recordId`；同片释文链接按该记录号调取。
- **JGW 字形编号**：`glyphs/` 目录 SVG 文件名，格式如 `008EAB-0A00-000001`；图注与文件名一致。
- **殷契文渊**：安阳师范学院甲骨学文献著录库（jgw.aynu.edu.cn），本书拓片缩略、SYSID、record 与同片释文的来源库。
- **释文标记**：同片释文中保留的 `a18`、`b02`、`c02` 一类采集 / 行标记，照录不改字；这类标记用于定位片上行款，**不据以判断释读**，释读分歧另按第五节处理。

## 五 · 选字与分卷原则

- **按事类分卷、逐字增补**：字位随卷次增补，不一次写成“全部”；新字先过字形、片号、同片释文、图版链路，再入卷。
- **本字 / 借字 / 后起字分标**：甲骨有本字者列本字；以假借字立形者标借字；甲骨无本字、后世产生者标后起字，三类状态在字头下逐条标明。
- **异说处理**：释读与字源分歧处，以通行说为主；其他说法标“一说待核”，不把异说写成定论。释文残缺处写“本片辞例仅见……，更完整用法待核”。
- **未收字**：未在本书登记的字头，留待后续轮次补位；首轮著录检索未命中者，改用可核字补位，不强行使用无出处字。
- **待查重字**：同一字头跨卷重复出现的，先登记重读位置，后续轮次并条；并条之前按字位计数，不按唯一字重复计数（见第六节“岁”字）。
