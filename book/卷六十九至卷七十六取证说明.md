# 卷六十九至卷七十六 · 取证说明

本批补的是《千字文》里“字库已有甲骨字形、书中尚未写成”的字。核对口径为《千字文》一千个字位、九百九十五个不重复字；已写成三百四十六字，字库有字形未写一百四十四字，两套开源字库都未直接查到五百零五字。

一百四十四个待补字，先按殷契文渊 `SW` 释文字段逐字反查：检索结果必须满足三条——释文含目标字、同片释文不少于四个汉字、记录形式含“拓片”。得到强证据九十七字、弱证据两字（宇、离，释文仅一至三字）、未检出四十五字。本批只收强证据中的九十六字，编为八卷；助、宇、离未编入，留待下一批。

八卷各十二字：

- 卷六十九 · 天时与年成：宙、冬、咸、气、时、青、冥、中、音、色、兹、乎
- 卷七十 · 宗庙与礼器：吕、陶、殷、朝、戎、盖、瑟、阶、设、对、华、罗
- 卷七十一 · 德行与性命：致、重、养、敢、效、能、传、福、非、孝、命、之
- 卷七十二 · 盛衰与言辞：盛、不、息、辞、无、别、卑、上、下、退、颠、乃
- 卷七十三 · 职官与册命：亦、隶、书、卿、县、刻、佐、勿、虢、翦、沙、主
- 卷七十四 · 草木与田稷：柰、羔、墨、野、于、载、稷、赏、孟、几、寻、荷
- 卷七十五 · 行止与衣食：条、游、攸、饱、巾、弦、举、足、且、骧、亡、任
- 卷七十六 · 余字与残义：金、垂、迩、惟、厥、辱、幸、两、皆、施、绥、者

每字证据链：

1. 以目标字在殷契文渊检索页做 `SW` 模糊检索，取含该字的释文记录；
2. 取该记录的片号、record、著录（`CC`）与拓片缩略 `smallPic`；
3. 以 `LoadSwPic?id=<SID>&name=sw` 取同片释文全文，节录入书；
4. 字形优先用 `hanzi-glyphs-svg` 的 JGW 层；JGW 未收的三十三字，用 EVOBC 开源字形 PNG 做轮廓矢量化，标“EVOBC 开源字形 · 矢量化复写”，不称原拓。

本批的边界：

- 咸、兹同见合7，拓片为同一片；两字图注都标“同片”，不把同片拓片当作重复凑图。
- 弱证据宇、离只有一至三字残文，不写成完整释文；未检出四十五字不补笔、不借用别字。
- 开源字形是摹形，不是原拓；拓片缩略只作同片证据，不替代整片拓片。
- 每字“字源”以《说文》与通行释读为底，遇到甲骨构形与后世字形不一致处，写明“甲骨作/借为”，不把后世结构套回甲骨。
