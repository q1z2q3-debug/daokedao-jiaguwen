# 前言 · 文与化

我们为什么从甲骨文开始？

因为“文化”这两个字，本身就藏着答案。

先说“文”。在甲骨文里，“文”常写成一个正面的人，胸前有交错的纹。那纹，可能是刺青，可能是画上去的图案，也可能是佩饰留下的痕。它先不是一篇道理，而是一道看得见的线。线落在人身上，也落在陶、玉、骨、石上；人看见它，知道它与自己有关。文，最初就是纹。

再说“化”。甲骨文的“化”，从人从匕。匕，是一个倒过来的人。这里的“匕”，不是“匕首”的刀；甲骨“匕”有象取饭之勺的一系，也有象反人、倒人的一系，在“化”字里取的是倒人。一正一反，像人翻了个身。所以“化”的本义是变、是转、是化生。它不是刀在石上留下的印；刀痕是“刻”，是“契”，是“书”的动作。变化是“化”，是人的转身。两者分开，文化才看得清：

文，是留下来的痕；

化，是人因这痕而变。

以文化人，不是把知识装进人，而是让人看见痕、认出痕，然后转身。

刀刻在甲骨上，先有“文”，后有“字”。文是纹样，字是纹样与语言签了约。从此，一道线不只像什么，还能读成什么；一个人不只看见图案，还能听见另一个人的话。

把“文”当“纹”看，美术就不是文化的装饰，而是文化的第一现场。人先画动物、画人、画日月，把世界变成可看的形；再把形压缩成可读的符。画、刻、塑、铸、写，本来不是几件事，而是同一条路：先有痕迹，再有形象，再有符号，最后有文字。所谓“大美术”，不是把画画、书法、工艺、文字分成几块，而是承认它们本来是同一条路的不同段落。

甲骨文不是中国文字的绝对起点。它之前还有陶器上的刻符、玉器上的刻画；它之后有金文、小篆、隶书、楷书、行书、草书。但甲骨文是目前所见最早、成体系、又能与卜辞互相印证的汉字系统之一。它把“形”与“言”扣在一起，让一个字既有样子，又有出处。

人会说，会忘；字会刻，会留。话一出口就散了，字落在骨上，能过火、过土、过千年。文字把一个人的记忆，变成一群人的记忆；把一代人的经验，变成下一代人的起点。美术让世界可见，文字让世界可传。文明之所以能延续，不只因为人活得久，更因为人留下的话，比人活得久。

文字本身也有各种创作形态。同一个字，在甲骨上是刀痕，在青铜上是铸痕，在纸上是墨痕；甲骨、金文、小篆、隶书、楷书、行书、草书，是同一个字在不同材料、不同时代里的身体。字体不是外壳，它是一个时代的手感，也是一个人写字时的呼吸。

所以，读甲骨，不是去认几个奇形怪状的字，也不是把今天的字套回三千年前。我们要把字放回它的片、它的辞、它的手、它的刀。先看它刻在哪里，再看它和哪些字一起出现，最后才问：它为什么长成这样。

这本书每字先给片号，再给拓片，再给同片释文，再给字源，最后才写“一世界”“一智慧”。有本字的，列本字；只有借字的，列借字；后起的，标明后起。不补笔，不空引，不拿别片充同片。甲骨不是万能的字典，它也有没造、没写、没留下来的字。承认这一点，比多画一个像字的图形更重要。

文是留痕，化是转身。留痕是为了不忘，转身是为了不再原地。文明，就是一代人把自己刻进骨头，下一代人从骨头里认出自己，再刻下新的痕。

这，就是我们读甲骨文的理由。
